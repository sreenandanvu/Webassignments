Client/Server Architecture

Definition of Client

A client is a device or application that requests services or resources from a server. A web browser is an example of a client.

Definition of Server

A server is a computer or system that provides services or resources to clients. It receives requests, processes them and sends responses.

Components of Web Application

View Layer

The View Layer is the part of a web application that users interact with. It displays information and provides the user interface.

Examples include web pages, forms, buttons and menus.

Business Layer

The Business Layer contains the main logic and rules of the application. It processes user requests and performs the required operations.

Data Access Layer

The Data Access Layer communicates with the database. It is responsible for storing, retrieving, updating and deleting application data.

Types of Web Content

Text

Text is used to display information such as headings, paragraphs, articles and descriptions.

Images

Images provide visual information and make web pages more attractive and easier to understand.

Audio

Audio includes music, podcasts, voice recordings and other sound content available on websites.

Video

Video is used for tutorials, education, entertainment, advertisements and other multimedia content.

Animation

Animation creates moving visual effects and can be used to make web pages more interactive.

HTTP and HTTP Request

Definition of HTTP

HTTP stands for HyperText Transfer Protocol. It is a protocol used for communication between web browsers and web servers.

HTTP Request and Response

An HTTP request is a message sent by a client to a server to request a resource such as a webpage or data.

An HTTP response is the message sent by the server back to the client after processing the request.

Working of HTTP Communication

  1. The client sends an HTTP request.
  2. The server receives the request.
  3. The server processes the request.
  4. The server prepares a response.
  5. The response is sent back to the client.
  6. The client displays the result.

Dynamic Web Pages

Definition

A dynamic web page is a webpage whose content can change based on user input, time, database information or other conditions.

Characteristics

  • Content can change according to user interaction.
  • Can use data stored in databases.
  • Can provide personalized content.
  • Can respond to user input.
  • Content can be updated automatically.

Examples

  • Online shopping websites
  • Social media websites
  • Online banking websites
  • News websites
  • Online learning platforms

Application Servers

Definition

An application server is a server that provides an environment for running web applications and their business logic.

Purpose

The main purpose of an application server is to process application requests, execute business logic and communicate with databases and other services.

Major Services

  • Application processing
  • Database connectivity
  • Security and authentication
  • Session management
  • Transaction management
  • Resource management

Web Security

Definition

Web security is the practice of protecting websites, web applications and user data from unauthorized access and cyber attacks.

Importance

Web security protects sensitive information, prevents unauthorized access and keeps web applications safe from different types of attacks.

Basic Security Measures

  • Use HTTPS for secure communication.
  • Use strong passwords.
  • Validate user input.
  • Use proper authentication and authorization.
  • Keep software and systems updated.
  • Protect sensitive user information.
