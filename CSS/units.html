CSS Units

Absolute units are fixed; relative units depend on another value.

UnitTypeDescription
pxAbsoluteOne CSS pixel (1/96 of an inch)
cm / mm / inAbsolutePhysical lengths
pt / pcAbsolutePoints (1/72 in) and picas (12 pt)
emRelativeFont size of the element
remRelativeFont size of the root element
%RelativePercentage of the parent value
vw / vhRelative1% of viewport width / height
vmin / vmaxRelative1% of the smaller / larger viewport side
chRelativeWidth of the "0" character
exRelativex-height of the font
