CSS Functions Reference

Functions compute values for properties.

FunctionDescriptionExample
calc()Math with mixed unitswidth: calc(100% - 240px);
var()Reads a custom propertycolor: var(--accent);
rgb() / rgba()Color from red, green, blue (and alpha)rgb(47 91 234 / 0.5)
hsl()Color from hue, saturation, lightnesshsl(220 80% 55%)
linear-gradient()Gradient image between colorslinear-gradient(90deg, #f00, #00f)
min() / max()Smallest or largest of the valueswidth: min(90%, 60rem);
clamp()Value kept between a minimum and maximumfont-size: clamp(1rem, 2vw, 2rem);
url()Points to a filebackground: url("bg.png");
translate()Moves an elementtransform: translateX(20px);
rotate()Rotates an elementtransform: rotate(45deg);
attr()Reads an HTML attribute valuecontent: attr(title);
repeat() / minmax()Grid track sizinggrid-template-columns: repeat(3, minmax(0, 1fr));
