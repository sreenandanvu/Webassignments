CSS Aural Reference

Properties for speech output. CSS2.1 aural properties are obsolete and replaced by the CSS Speech Module, which has very limited browser support.

PropertyDescriptionStatus
speakWhether content is read aloudCSS Speech
speak-asHow text is spoken: spell-out, digits, punctuationCSS Speech
voice-familyChooses the voiceCSS Speech
voice-pitchPitch of the voiceCSS Speech
voice-rateSpeaking speedCSS Speech
voice-volumeLoudnessCSS Speech
pause-before / pause-afterSilence around an elementCSS Speech
cue-before / cue-afterSound played around an elementCSS Speech
azimuthHorizontal sound positionObsolete (CSS2.1)
play-duringBackground sound while speakingObsolete (CSS2.1)
